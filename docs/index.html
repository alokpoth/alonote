🔒 100% Offline & Private

No internet permission, zero tracking SDKs, no accounts, and no cloud synchronization. Your private notes stay exclusively in your device's local Room database.

✨ Apple-Inspired Monochrome

Minimalist black, white, and subtle gray palette with clean typography, rounded surfaces, and a translucent floating bottom navigation bar.

⚡ Debounced Autosave & Pinning

Edits save instantly as you type. Long-press any note to Pin to top, Star as favorite, or Delete. Empty drafts are cleaned up gracefully.

🚀 Modern Native Stack

Engineered using Kotlin, Jetpack Compose, Material 3, Room SQLite, Navigation 3, and Coroutines/Flow with clean MVVM architecture.
