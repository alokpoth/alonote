🔒 100% Offline & Private

No internet permission, zero tracking SDKs, no accounts, and no cloud synchronization. Your private notes stay exclusively in your device's local Room database.

✨ Apple-Inspired Monochrome

Minimalist black, white, and subtle gray palette with clean typography, rounded surfaces, and a translucent floating bottom navigation bar.

⚡ Direct UI Actions & Pinning

Instant 1-tap UI buttons to Pin to top, Star as favorite, Copy, or Delete right on note cards. Grid and list views with real-time word counting.

🚀 Native & 120 FPS Smooth

Engineered using Kotlin, Jetpack Compose, Material 3, Room SQLite, and Coroutines/Flow with clean MVVM architecture and zero typing lag.
